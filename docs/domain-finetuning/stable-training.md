# 当前多轮训练

[返回总览](README.md) · [训练基础](training.md) · [评估](evaluation.md)

本轮使用修订后的1000条正样本，800条训练、100条验证、100条最终测试。
只训练多图版本，使用 qwen3vl；原始代码、数据及历史结果保留。
当前进度以运行目录里的 status.json 为准；[已完成检查](current-run.md)另行记录。

## 启动及恢复

```bash
scripts/train_stable.sh outputs/finetune-20261115
```

依次完成输入核对、两版答案编码、16条短训练、继续训练、保存重载、
初始模型验证、正式训练、模型锁定、最终测试与数值对照。
同一命令恢复未完成阶段；进程锁防止同一目录同时启动两次。
数据、图片、标注、初始模型不一致时拒绝恢复。
正式训练恢复还检查提问、设置和图片模式；整轮中断会重新训练该轮。
本轮从初始模型新开，旧实验保存文件不能混作本轮恢复点。
首次短训练若在保存前失败，先查明问题；不能删除历史日志后冒充成功。

## 停止与选择

最多20轮，第1轮只训练区域，其余轮联合学习中文与区域。
沿用每条1个样本、累计8条更新和既有输入尺寸、学习率。
每轮独立预测全部验证图片，不把标准答案或区域输入预测。
三来源平均重合分数等权作为主要分数，始终保留实际最高分模型。
联合训练第一轮建立参考；相对上次明显进步累计提升至少0.002时重置计数。
至少完成5轮联合训练，连续4轮未明显进步时停止。
停止计数、参考分数、最佳分数随保存文件恢复。
达到上限不称为稳定；零分、退步和明显波动分别记录。
文字正确性不由区域分数自动证明。

## 结果位置

- runner.log、status.json：阶段进度和失败状态。
- input_hashes.json：数据、图片、标注和初始模型核对记录。
- smoke/、reload-check.json：短训练、继续训练及重载证据。
- baseline-val/：初始模型在验证集上的自由预测。
- multiview/train.jsonl：每条损失、耗时和显存记录。
- multiview/epoch-*.json：每轮验证、停止状态和耗时。
- multiview/best.pt、last.pt：最佳模型和可恢复的最新模型。
- multiview/val-epoch-*/review/：固定每类10条的图文对照。
- final-models-locked.json：训练结束后锁定最佳模型及最终测试集。
- baseline-test/、finetuned-test/、comparison.json：最终对照。

review/status.json 默认标为未查看，生成拼图不能冒充已经复核。
最终评估只在模型锁定后执行，不据其结果再调整模型。
所有来源只有正样本，不能评估无滑坡图片误报率。
