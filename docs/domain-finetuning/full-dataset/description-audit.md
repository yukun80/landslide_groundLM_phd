## 哪些描述值得先改

- 原先缺少光学外观的 2,646 张中，有 1,078 张得到修改建议。较可靠的补充是标注区大部分明显偏亮、偏暗或偏绿。有些图像目标只有几个像素，保留位置、面积比强加纹理描述更稳妥。
- 118 张涉及从光学明暗推断表面高低。图上有深浅变化，可以描述深浅；要断言“凹凸不平”还需要能分辨该起伏的证据。
- 13 张小目标纹理疑点和 10 张先前修复的图都已直接对照原图和标注。历史颜色疑点共 2,087 张，本轮对每条当前颜色句检查标注内的颜色支持程度，其中 83 张有修改建议。其余 2,004 张仍需判断，不因曾经有疑点就直接改。
- 先前已有 28 张保存过另一份建议。本轮逐一看图比较。它们的原建议保留在表格倒数第二列，便于与本轮建议对照。

## 检查覆盖到哪里

全部图像均核对了两版原文的来源，从有效标注重新计算方位、面积、多块或连续分布和外框。未发现这些内容与原文不一致。逐图读取了光学图、标注和附带的辅助图，对照目标及邻近有效背景；每张图的测量结果在清单中。全文含有外观句时，也逐句检查颜色反证。色调的占比适合发现整体判断的问题，局部颜色占比低本身不能否定其存在。

本轮直接看图 44 张，覆盖全部 28 张既有建议、13 张小目标纹理疑点，以及每个来源各 1 张保留样本。其余记录使用逐图测量和已有观察记录判断。保留表示有既有看图依据、且本轮没有发现需要改的内容。待确认表示对局部纹理、边缘、背景关系或是否可以补写外观仍缺少可靠依据。按已有支持程度给出的修改建议，也不构成对同一段所有其余细节的确认。
