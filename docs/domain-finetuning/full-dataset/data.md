# 数据范围、清洗与划分

[返回总览](README.md) · [下一节：文字](descriptions.md)

## 三套数据与实际模型输入

|来源|复制保存|送入模型的图片顺序|
|---|---|---|
|GDCLD|原始影像和分割标注|RGB|
|Landslide4Sense|完整14波段影像和标注|近红外/双短波红外假彩、RGB|
|多模态滑坡|完整光学/InSAR/DEM影像和标注|InSAR、DEM、RGB|

波段索引沿用原1000条：GDCLD RGB `[0,1,2]`；L4S假彩 `[7,10,11]`、RGB `[3,2,1]`；
多模态 InSAR `[4,4,4]`、DEM `[3,3,3]`、RGB `[0,1,2]`。索引从0开始。
区域输出始终对应最后一张光学图，不对应辅助图。
不新增其他数据来源，也不把L4S的高程/坡度增加为训练图片。

## 清洗顺序

1. 枚举三份原转换清单的全部记录，逐个实际读取标注。
2. 排除无效标注、非法标签、损坏文件、必要图片不可用等情况。
3. 有效光学区域内必须至少有一个滑坡像素；三套来源、所有划分都排除纯背景。
4. 不另设高面积门槛；微小目标在训练读取时检查仍然存在。
5. 完全相同图片和标注优先保留已固定样本，其余重复记录说明代表项。
6. 相似图片先定位候选，再比较真实结构；相似本身不等于同一张图片。

## 划分规则

按来源尽量接近训练/调参/测试80/10/10，固定随机种子20261116。
999条可用旧样本保持原划分和原答案，全黑样本按用户要求排除；独立500条及其同组数据只进入测试部分。
同一父图、同一真实图片及已确认近重复归入同组；已知地理范围不得跨划分重叠。
固定样本或真实分组优先于精确比例，实际数量见检查记录。

GDCLD中独立原图的相同数字序号不代表同一地点，使用完整来源编号。
缺少地理信息的来源不能声称做到了跨地区独立评估。
本数据全是有目标样本，不能用于衡量纯背景误报。

## 保存位置

`raw/来源/编号/` 是完整实物副本，不是链接；`samples/编号/` 是显示图片、有效区和滑坡标注。
`audit/inventory.jsonl` 记录每条来源的读取结果；`partition_exclusions.jsonl` 记录去重/重叠排除。
显示范围固定为旧1000条中原训练800条确定的范围，不使用新测试数据重新调整颜色。
