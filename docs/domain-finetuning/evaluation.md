# 评估

[返回总览](README.md) · [上一步](inference.md) · [下一步](validation.md)

旧对照流程比较原始模型、光学微调模型、多图微调模型。
[当前多轮训练](stable-training.md)仅比较初始模型和多图微调模型，使用独立锁定记录；
评测入口通过 `--lock` 指定该记录，不能复用旧实验锁定文件。
每轮仅使用val进行模型选择；正式训练全部完成并锁定后，才运行test。

```bash
scripts/domain.sh eval/domain.py --split val --output outputs/baseline-val
scripts/domain.sh eval/domain.py --checkpoint outputs/multiview/best.pt --split val --output outputs/multiview-check
```

区域评分排除无效像素，分别记录重合、漏掉、多画的像素数。
通用评分程序支持背景样本，但本版数据没有背景样本，不据此给出误报结论。
每来源报告平均分；选模型时三来源等权。
三个来源均只评估有目标样本，不能声称其背景误报已经验证。

文字自动检查仅识别部分明显越界词语及文字与区域冲突。
需要逐图核对位置、面积、遗漏及无依据结论，自动检查不能代替审阅。
审阅样本固定为val每来源10个；最终样本在模型锁定后核对。
当前描述包含标注计算说明和部分经模型看图修订的外观句，尚未人工逐图确认。
句式相似不等于识别准确。

辅助图缺失和替换检查仅在val执行，不利用test反复调试。
最终比较必须报告各来源退步情况、样本数量与结果波动。

文字声称有目标的误报与实际画出区域的误报分别统计；空区域不能替文字误报免责。
无法解析的回答另计，不当作正确识别。

本版三个来源均为有目标样本；背景误报指标没有可评估样本，应显示为空，不表示误报为零。
