# 滑坡领域微调

[返回项目入口](../../README.md)

目标：使用至多1000个原始样本，让 Xiaomi-Lens-0 标出滑坡并给出中文位置、范围说明。
不识别灾害细类，不推断成因、危险等级或未经确认的位移速度。

## 阅读与执行顺序

1. [模型与环境](model.md)：优先复制已有模型，原目录保持不变。
2. [数据准备](data.md)：三类数据、固定划分和所有来源空标注剔除。
3. [训练](training.md)：16例短训练与两阶段训练；[本轮多轮训练](stable-training.md)只运行多图版本。
4. [预测](inference.md)：多张图片的顺序与结果保存。
5. [评估](evaluation.md)：自由预测评分、评估范围和文字核对。
6. [本轮运行记录](current-run.md)：当前启动检查与进度；[历史验证](validation.md)保留原范围。
7. [代码地图](code-map.md)：新增文件职责。

程序能够运行与识别效果得到改善是两项独立结论，实际结果以验证记录为准。
