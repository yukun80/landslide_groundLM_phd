## 4. 唯一一条活动判别（B 口径）

`multimodal_landslide_xiz_001834`（试点）多图版末尾写：

```text
InSAR 编码值灰度图中央偏下有相对偏亮连片区，提示形变较大；结合光学图片状轮廓与 DEM 平缓浅灰渐变，判断为活动滑坡。
```

该句**只出现在多图版**，由用户在试点确认阶段明确授权；`channel_schema.json` 无法核实 `|v|>20 mm/yr`，灰度偏亮不等于形变绝对值大，结论不是由本地数据计算得出，也未经人工确认，已写入该样本的 `uncertain`。全量 1000 条中仅此 1 条。
