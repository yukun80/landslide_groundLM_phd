## 图片与答案如何对应

每条样本通过同一编号关联输入图片、滑坡标注、有效区域及两版文字。
`answer` 保存多图版，`answer_optical` 保存仅光学版。
训练入口使用共享选择函数：只输入光学图时选光学版，其余选多图版。
只有真正没有新增字段的旧格式允许回退；已有光学字段却为空会明确报错。

输入图片仍是样本的原有视图：辅助图在前，光学图在最后。
区域标记和mask始终对应最后的光学图。
本次用于复核的标注叠加图及目标像素核对图不进入正式训练输入。

## 输入尺寸

GDCLD的1024平方光学图缩到最长边512。
Landslide4Sense和多模态来源的128平方图片放大到最长边256。
所有图片的处理规则由共用运行代码决定，不能把放大后猜测的细节当成事实。

## 文字与区域标记

文字以原标注计算的位置、面积和连续/多块分布说明开头。
新增外观说明放在其后，末尾的bbox和mask标记仍由原标注计算。
改写外观不能修改基础数值或区域标记。
官方坐标解析、两版选择与保存续接均需实际检查。

## 长度和读取检查

训练输入上限2048，回答生成上限160；字符数量不等于模型处理的文字长度。

```bash
scripts/domain.sh tools/smoke_desc_v2_loader.py --mode encode
scripts/domain.sh tools/check_domain_data.py
```

第一条实际构造两种输入并检查所有样本的长度，不加载权重或启动训练。
第二条检查数据、目标和标记；当前共享校验已兼容新增外观句。
本轮检查结果单独保存，不能覆盖历史通过或失败记录。
