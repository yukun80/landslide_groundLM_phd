### 一张真实图片的完整预测

使用仓库附带的右侧花瓶图片及原问题，实际运行了“读取图片→自由生成文字→读取区域标记→区域解码→绘制图片”。

- 使用现有本地 Xiaomi-Lens-0 模型；环境为 torch 2.10.0+cu128、transformers 5.4.0，CUDA 可用。
- 为稳定比较，两版均使用 SDPA，图片处理像素范围为 65536～262144，最多生成 512 个新文字单元，使用相同随机种子和贪心生成。
- 两版最终回答完全相同，框为 `[592, 304, 755, 938]`，最终答案含一个区域，没有思考区域。
- 两版区域分数逐数值一致，输出图片逐像素一致，模型画布为宽 576、高 416。
- 已打开检查叠加图片，标色区域落在右侧花瓶。没有计算这一例与人工标注的正式准确率，不将视觉检查当作完整模型评测。
