# 结果怎样评分

[返回上级](../README.md)

打开 [eval/run.py](../../../Xiaomi-Lens-0-raw/eval/run.py)，按 `score_masks` → `summarize` → `predict_hf` → `main` 阅读。先理解单图评分，最后再看分卡与服务部分。

- `IoU`：预测与标注共同选中的像素数，除以至少一方选中的像素数。
- `Prec@0.5`：本文件里是 IoU 达到 0.5 的样本比例，输入是区域并集，不是用回答文字中的框计算。
- `cIoU`：所有样本交集加起来除以所有并集加起来，大区域的影响较大。
- `gIoU`：此处指逐样本 IoU 的平均，不是框检测中常见的 Generalized IoU。

例如两条记录分别为交集/并集 `1/2` 与 `90/100`，逐例平均是 0.7，总体面积比却是 `91/102≈0.892`。两种分数回答的问题不同，不能互换。

本实现将预测与正确区域都为空的情况记为 IoU=1。没有生成答案区域时预测为空。默认后处理先缩放连续分数，再用阈值选像素；比较分支会尝试先二值化后最近邻缩放，二者可能不同。

自测：只评估少数样本、程序正常结束，是否等于完整 LensBench 完成？**不是。代码另行检查所需样本数、覆盖范围和完成标记。**
