# Xiaomi-Lens-0 学习总览

[返回上级](../README.md)

这套代码做的事是：你给它一张图片和一个问题，它不仅可以用文字回答，还可以指出回答涉及的像素区域。例如问“右边的花瓶在哪里”，输出文字中的框坐标，再给花瓶所在像素着色。

不要从第一个文件第一页一路硬读到最后。先跟踪“一张图的一次预测”，建立整体印象；第二遍再研究内部计算；第三遍看训练和评测。源文件中的「中文导读」「步骤说明」和计算旁注都为这条路线服务，英文原说明完整保留。
