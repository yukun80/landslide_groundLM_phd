# 500条独立样本

[返回总览](README.md)

数据来自共享 benchmark 的 oa_auxseg_hdf5_v1/full，保存于项目 datasets/landslide_benchmark_500。
高分辨率光学200条、多光谱150条、多模态150条，全部为有效滑坡正样本。
实际来源划分：GDCLD验证200条、Landslide4Sense测试150条、多模态验证150条。
优先测试、再验证、最后训练；已知同源原图被排除后，GDCLD本次由验证部分补足。

## 如何排重

排除旧训练、验证、测试共1000条，不仅排除800条训练样本。
核对来源编号、原始图片内容记录、原图分组、图像相似性与已知地理重叠。
辅助图不重复计数；同一样本各种显示方式不算新样本。
没有地点信息的来源不能证明完全跨地区独立。

## 复制与显示

每样本复制一份data.h5，保存benchmark中的数值、有效性和辅助观测。
另生成光学/辅助显示图片、标准区域、有效区域；不使用软链接。
显示范围沿用旧训练集固定范围，不在新测试样本上重新拟合。
benchmark已统一到224×224，不能将其称为原始分辨率；放大不补回细节。

benchmark未独立存储标签有效区，准备时只读其记录指向的源标签，
恢复有效区并核对重采样后的标准区域与benchmark一致，再与光学有效区相交。
这些信息已复制到项目内，页面与批量预测不依赖外部源数据。
无目标、损坏、全部无效、无法确认有效区的候选不会入选。
本数据不提供人工文字标准答案，不用模板文字作为描述准确率依据。

## 清单

- samples.jsonl：图片对应、源记录、有效像素数及各复制文件核对值。
- screening.jsonl：逐项筛选原因及最终入选清单。
- manifest.json：数量、种子20261116、旧数据核对值和限制。
- outputs/benchmark500/data-check.json：独立检查结果。

只含有目标样本，不能根据本次结果评价背景误报。
源数据、旧1000条、原始代码和模型权重均不改写。
