# 定位框与彩色TIF

[返回总览](README.md)

样本和普通上传页面默认同时显示红色分割区域、黄色模型定位框。
两者可分别隐藏；框旁编号对应坐标清单。
框直接取自模型最终回答，不从分割区域反推，不把一个框当成一处独立滑坡。
错误或缺失框会提示，原始输出仍保留。
历史500条的新增展示存于outputs/benchmark500/localization，原结果和下载包不变。

## TIF操作

1. 打开“TIF整图与地理坐标”，上传已经配色的8位RGB/RGBA TIF。
2. 如有辅助图，选择对应类型并确认已经对齐；程序核对尺寸和已有地理信息。
3. 点击“准备图片并预览”，查看尺寸、地理信息、分块数量，保存任务编号。
4. 点击“开始或继续扫描”，查看进度、整图预览、分块回答和坐标。
5. 可点击“停止扫描”；当前块完成后停止。重新开始会核对并复用已完成结果。
6. 服务重启后填入任务编号，点击“读取已有任务”，再继续扫描。
7. 完成或停止后下载结果；未完成或失败部分不会被当成背景。

只支持通道含义明确的单页8位彩色TIF，不自动猜波段、拉伸配色或纠正辅助图位置。
只有控制点或卫星定位参数的TIF须先地理校正。无地理信息仍可预测，只给原图位置。
普通PNG/JPEG/WebP继续使用原上传页面，也可作为已经对齐的TIF辅助图。

## 坐标与文件

框坐标采用像素外边界：左上(0,0)，右下(width,height)，x向右、y向下。
地图四角按左上、右上、右下、左下排列，保留原坐标系与单位。
经纬度以经度在前，四角和沿边加密后的范围分别保存；日期线附近的范围拆分。
地图坐标转换失败不影响原图坐标保存，错误原因单独记录。

下载包包含：

- boxes.json：模型框、原图位置、地图四角、经纬度和异常信息。
- boxes.geojson：经纬度框，可在地图软件打开；没有有效地理框时为空集合。
- segmentation.tif：原图大小的分割结果，保留已有坐标系和图片—地图对应关系。
- answers.json：逐块原始回答；没有自动合成的整图地质描述。
- summary.json、status.json：完成、失败、覆盖范围与各类像素数量。
- view_1_1.png：整图缩小预览；tiles目录包含逐块结果及原始模型输出。

分割TIF数值：0背景、1预测目标、254未完成或失败、255无效区。
预览中灰蓝是未完成，暗灰是无效；黑白预览中白色目标、黑色背景、灰色未完成或无效。
所有下载坐标对应原图，不对应缩小后的网页预览。

## 分块规则与限制

默认512×512，相邻重叠128；边缘保留实际尺寸，不人为填充。
重叠像素归覆盖它且中心最近的块，等距时归先处理的块；不投票放大目标。
完全相同的框合并展示并保留所有来源块；仅交叠的框不合并。
分块结果有边界差异，框可能重复或包含多个目标，框数量不是滑坡数量。
单块失败会记录并允许重试，失败块保留未完成状态；不自动改模型或跳过失败。
输入、问题、模型和分块设置固定后才能继续，改变问题须新建任务。
