# 启动与使用

[返回总览](README.md)

在项目根目录运行 `scripts/start_demo.sh`，浏览器打开 http://127.0.0.1:7860 。
启动脚本使用 qwen3vl 中已有的 Gradio 6.20.0，并让本机访问绕过代理；不开启公开分享。
现有环境无需重新安装依赖，版本已记录在 requirements-domain.txt。
如果服务已启动，直接打开地址，不要再次运行同一服务。

## 样本测试

选择来源，用样本编号搜索，或点击上一条、下一条。
光学图和辅助图分别显示；标准标注折叠展示，不输入模型。
已完成的固定批量结果直接显示，不需要重复预测。
点击“开始推理”才运行新的交互预测，可修改问题。
新回答、区域、叠加图和下载文件单独保存，不改写批量成绩。
同一页面相同输入在上次完成后15秒内重复点击会复用结果，避免重复预测。
回答与根据预测区域计算的位置、面积分别呈现；两者可能不一致。

## 上传测试

此页支持已制作好的PNG、JPEG、WebP显示图片，不自动解析遥感原始波段。
彩色TIF请用“TIF整图与地理坐标”页，见[定位框与彩色TIF](localization.md)。
选择仅光学，或光学加近红外/短波红外，或光学加InSAR和高程。
辅助图必须和光学图同尺寸、同区域，上传者应确认已经对齐。
多光谱辅助图是按训练显示规则制作的近红外/短波红外彩色合成图。
InSAR与高程也必须按已有显示规则制作，不能随意换一种颜色映射。
缺少必要图片、数量不符、损坏或尺寸不一致时会提示错误。
上传图片没有标准标注，因此不显示区域准确性分数。

## 批量结果

“批量结果”页可刷新分来源成绩、样本明细及失败清单，下载完整结果。
固定批量测试使用训练时问题、输入尺寸和生成设置，不用自定义提问成绩替代。
批量运行时可以浏览已有结果，新的交互预测暂时等待批量完成，避免重复占用显存。

```bash
scripts/domain.sh tools/run_benchmark500.py
```

相同输入和模型可续跑，已完成结果复用；不同输入或模型拒绝混用。
预测失败单独记录，不计作成功；修复原因后原命令重跑可补齐。
